# Khodroyab Roadmap

## Current baseline
- Main includes the mutation Server Actions architecture and Quality CI.
- Quality CI covers ESLint and TypeScript typecheck.
- Catalog/import work is intentionally frozen.

## Next product stage: mobile-first discovery UX
1. Replace the vehicles-page search input interaction with a dedicated search page.
2. Move province/city selection to a dedicated mobile page flow.
3. Preserve the existing server-side search action and filter semantics.
4. Keep the fixed five-item mobile navigation and the prominent vehicle-registration action.
5. Validate vehicle list/detail/favorite flows after the navigation changes.
6. Do not change catalog data/modeling during this stage.

## Later
- Vehicle detail visual polish and listing history.
- Market analysis improvements: filtered ranges, count, average mileage, cheapest listing.
- Catalog design/import from scratch after the catalog freeze is lifted.
